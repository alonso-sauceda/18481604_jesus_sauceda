# LAB-01 — Protección y privacidad de datos

**Materia:** Gestión de Seguridad y Desempeño de Bases de Datos  
**Unidad:** II — Seguridad, privacidad y control de acceso  
**Estudiante:** Jesús Alonso Sauceda Soto (18481604)

## Objetivo
Aplicar mecanismos de protección de datos en PostgreSQL de acuerdo con el propósito y nivel de acceso requerido por diferentes usuarios de una organización, incluyendo clasificación, enmascaramiento, seudonimización, anonimización y retención.
